# Kiesel: Farbkapitel für unser bestehendes Handbuch

Wir haben ein kleines Web-Werkzeug für Schichtplanung. Es wird auf Desktop und im mobilen Browser benutzt, ohne native Apps. Die vorhandene Oberfläche ist hell; einen Dark Mode bieten wir nicht an. Im Produkt gibt es Listen, Eingaben und einen Speichern-Button. Diagramme haben wir aktuell nicht; eine spätere Auswertung wird diskutiert.

Bitte dokumentiere unseren vorhandenen Farbstand als übersichtliches Handbuchkapitel. Die vorhandenen Quellen sind in diesem Ordner. Wenn du eine fachliche Klärung brauchst, frage mich gezielt. Ich möchte aus dem Kapitel erkennen können, was bereits feststeht und welche Entscheidungen noch ausstehen.

Dies sind synthetische Testunterlagen eines fiktiven Produkts, keine Firmendaten.
