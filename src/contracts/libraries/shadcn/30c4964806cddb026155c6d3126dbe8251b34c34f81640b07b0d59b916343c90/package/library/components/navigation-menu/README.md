# NavigationMenu · semantische Komponentenreferenz

Expose real website navigation links with optional disclosure panels, distinct from an application command menubar.

Status der neuen Domänenmigration: **complete** im begrenzten Referenzumfang. Stabile Teile, tatsächlich passende Source-Selektoren, semantische Tokenwerte und nutzbare Zustands-Fixtures wurden mit dem normalen Komponentenprüfpfad und der echten React-Verwendung geprüft. [Browsernachweis](../../validation/semantic-layers-browser-run.json); keine allgemeine Anwendungsfreigabe.

Native triggers are 36px with 10px corners; content cards use 8px corners,8/16px inset,4px gap and 14/20 Medium title/description. The native description text field says Medium despite its Regular style label, so this reference explicitly keeps the observed Medium field and muted role. Native 290px card width becomes a preferred maximum. Popup 12px corner/1px border/4px content pad are explicit reference surface choices; source 350ms position/size/content opacity timing is retained with reduced-motion duration 0.01ms; source Positioner/Popup width/height/origin variables remain actual measured geometry. Root automatically appends one Positioner; no extra default instance is added. Source Root and private Popup are native navigation landmarks, not menu roles; the private popup has no invented label prop. Active/current-page link and open disclosure value remain distinct. Destination links choose closeOnClick=true in target, while the source default remains false. Root/Trigger keyboard, disabled focusability, hover delay and controlled cancellation retain pinned primitive rules. Theme/dir are document context because the built-in private Popup cannot receive arbitrary Root data-theme props. Trigger aria-controls identifies the actual private nav Popup, not its Content child. No page/frame/node selectors or fixed source sample positions survive.

Selectorbindungen sind ein expliziter React-/DOM-Adaptervertrag, keine erfundenen automatischen Shadow-DOM-Exports.

Root is native nav (nested primitive Roots use div), not role=menu or menubar. Generic value/defaultValue is the currently open item or null; it is distinct from the destination/current-page link. onValueChange carries cancellable details, and controlled props remain authoritative. Source delay/closeDelay default50ms, orientation defaults horizontal. The wrapper align defaults start and automatically appends one NavigationMenuPositioner: do not add a second one to this wrapper. Its built-in Positioner defaults bottom/start and offsets8/0; custom default-positioner side/offset composition needs the direct primitive Root, not fictitious Root props. Content moves into the active popup/viewport; the private source Popup itself is another native nav without an exposed label prop, while accessible destination links remain related to the named outer navigation in the client accessibility tree. Trigger is native button with expanded/controls, no invented menuitem role; disabled triggers may focus but cannot open. List/Item remain ul/li with primitive composite navigation (loopFocus=false on the top list). Link is a real anchor, active sets aria-current=page, closeOnClick defaultsfalse. This reference explicitly selects closeOnClick=true for actual destination links. NavigationMenuIndicator wraps primitive Icon (a decorative disclosure indicator), not an independent selected-item controller. onOpenChangeComplete is emitted with false after closing/unmount, not an invented opening callback. Deferred closing uses eventDetails.preventUnmountOnClose and actionsRef.unmount.

Native links keep normal navigation and modified clicks. Horizontal trigger navigation uses source Left/Right; Down opens an eligible disclosure while retaining trigger focus; native Tab enters its first destination, vertical orientation uses its direction-aware opening key. Focus and open item are separate from route/current-page state. Escape dismisses the applicable popup and restores its owner when source reason/focus policy permits; outside/focus-out/actual navigation need not forcibly steal focus back. Hover is supplemental and has source delay/safe-region behavior. Disabled triggers cannot activate; essential destinations are real named links.
