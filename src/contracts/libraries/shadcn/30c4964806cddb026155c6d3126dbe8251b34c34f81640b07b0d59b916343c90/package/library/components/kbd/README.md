# Kbd · semantische Komponentenreferenz

Display a keyboard key or shortcut notation in text.

Status der neuen Domänenmigration: **complete** im begrenzten Referenzumfang. Stabile Teile, tatsächlich passende Source-Selektoren, semantische Tokenwerte und nutzbare Zustands-Fixtures wurden mit dem normalen Komponentenprüfpfad und der echten React-Verwendung geprüft. [Browsernachweis](../../validation/semantic-content-browser-run.json); keine allgemeine Anwendungsfreigabe.

The actual two exports render native kbd elements.20px minimum keycap height,6px corners,4px inline inset and12/16px text retain native metrics. The21px specimen width is glyph-dependent and stays in evidence. Group notation wraps at its host boundary, while no tabstop, role=button or automatic shortcut handling is added.
