# Badge · semantische Komponentenreferenz

Show a short status or category adjacent to content.

Status der neuen Domänenmigration: **complete** im begrenzten Referenzumfang. Stabile Teile, tatsächlich passende Source-Selektoren, semantische Tokenwerte und nutzbare Zustands-Fixtures wurden mit dem normalen Komponentenprüfpfad und der echten React-Verwendung geprüft. [Browsernachweis](../../validation/semantic-content-browser-run.json); keine allgemeine Anwendungsfreigabe.

Badge uses the actual six CVA variant classes and native22px minimum height,8/2px insets,4px gap,12/16px medium text and12px optional glyph. Native sample widths depend on wording and are never fixed. Borders are included in the22px box; content may enlarge it. The default informative span is not focusable or activatable. Only explicit caller anchor rendering gets hover/focus link rules and a real destination; variant=link alone does not invent link semantics.
