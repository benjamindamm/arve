# Calendar · semantische Komponentenreferenz

Select actual local calendar dates with distinct selected value, keyboard focus and displayed month.

Status der neuen Domänenmigration: **complete** im begrenzten Referenzumfang. Stabile Teile, tatsächlich passende Source-Selektoren, semantische Tokenwerte und nutzbare Zustands-Fixtures wurden mit dem normalen Komponentenprüfpfad und der echten React-Verwendung geprüft. Stable actual Calendar slot, exported DayButton and DayPicker classNames identify parts, never locale-formatted data-day values or native node IDs. Native 38/28/48px day sizes and 10px corners remain semantic role tokens; source 6px calendar-navigation corner is retained. Default 38px cells,8px root inset and explicit week/caption spacing make a reusable intrinsic calendar; compact 28px is an explicit data-calendar-size caller attribute, not a new upstream size prop. Calendar Root is unframed by default; a surrounding Popover/Card owns its frame. Optional dropdowns/week numbers and noninteractive mode retain actual source DOM. Native range/today/outside/disabled/hidden/selected states use actual DayPicker modifier classes and exported Button data-range attributes. One roving native day tabstop and an attached-ref components.DayButton reference repair preserve source handlers while fixing the pinned wrapper omission; unchanged raw wrapper remains a negative runtime regression. Date selection, keyboard focus, displayed month and caller validation remain separate. Local dates and meaningful names are explicit reference usage. No fixed specimen dimensions or universal AT claim.

Selectorbindungen sind ein expliziter React-/DOM-Adaptervertrag, keine erfundenen automatischen Shadow-DOM-Exports.

Calendar forwards the full React DayPicker 9.14.0 discriminated prop union (mode absent|single|multiple|range, required variants) plus buttonVariant. shadcn defaults showOutsideDays=true, captionLayout=label, buttonVariant=ghost; locale, formatters, classNames and components are explicit overrides. CalendarDayButton is the exported native shadcn Button adapter, attempting to synchronize focus when modifiers.focused changes, but the pinned wrapper omits attaching its ref: raw keyboard focus is broken while internal focused modifiers advance; data-day is locale-formatted, never a stable ISO identifier. DayPicker selection is Date|Date[]|DateRange|undefined according to mode/required. Supplying onSelect makes the selected prop authoritative even when undefined; without onSelect the primitive owns internal selection. onSelect(selected,triggerDate,modifiers,event) is separate from onDayClick(date,modifiers,event); the source calls selection first, onDayClick afterward. DayPicker itself prevents default and propagation on day click; defaultPrevented is not a generic veto/cancellable eventDetails API. Optional single may clear by selecting the same date; required single does not clear. Multiple min/max and range min/max/excludeDisabled/resetOnSelect are source algorithms, not assumed to be the same toggle. excludeDisabled resets a candidate range crossing a disabled date to its new start. disabled is a Matcher or Matcher[], hidden differs from disabled, and no synthetic root disabled boolean is invented. Displayed month/defaultMonth/onMonthChange is independent from selected date; startMonth/endMonth bound month navigation, not selection by themselves. Selection need not submit a form. Root is a named div by default, each month table is the source named grid, with native day buttons, registered roving tabIndex and labelled selected/today dates. Noninteractive mode omits day buttons. Footer is the primitive polite status; essential validation instructions remain persistent outside it.

The explicit reference components.DayButton adapter forwards an attached ref through exported CalendarDayButton rest props and focuses it on modifiers.focused, preserving original styling and handlers. This repairs the observed pinned source omission; raw wrapper behavior is preserved as a negative browser regression. The active day has one tabIndex=0; source focus navigation skips disabled/hidden dates. Left/Right move a day (RTL reverses), Up/Down a week; Shift+Left/Right move a month and Shift+Up/Down a year. PageUp/PageDown move month, Shift adds year; Home/End move to week boundaries. Native Enter/Space selects the focused eligible day. Keyboard focus can move without selection. Navigation arrows have source native disabled boundaries. Calendar alone has no Escape dismissal or focus trap. Caller-provided components/labels must preserve the source refs, event handlers, names and native semantics.
