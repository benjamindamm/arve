# Toast · semantische Komponentenreferenz

Present nonmodal actionable notifications with actual manager, announcement, timer, focus and close/remove lifecycle.

Status der neuen Domänenmigration: **complete** im begrenzten Referenzumfang. Stabile Teile, tatsächlich passende Source-Selektoren, semantische Tokenwerte und nutzbare Zustands-Fixtures wurden mit dem normalen Komponentenprüfpfad und der echten React-Verwendung geprüft. [Browsernachweis](../../validation/semantic-layers-browser-run.json); keine allgemeine Anwendungsfreigabe.

Native toast 18px corners,16px inset,12px gap and double 10% black shadow offsets are retained.382px native width is a preferred maximum rather than a fixed sample box; viewport margin 16px bounds narrow screens. The pinned source collapsed/expanded stack is translated into readable component rules: measured height/offset/index,12px peek,0.1 index scale step, native pointer swipe movement and source 500ms transform/opacity,150ms height and 250ms content opacity. Source limited objects stay inert/transparent, source behind content is hidden until expanded, and close/removal remain distinct after actual CSS transition. Reduced motion chooses 0.01ms finite transition rather than waiting on invisible 500ms motion. Native natural-height measurement temporarily sets Root height auto, preserving longer text/actions without fixed 72px clipping. Source Close is aria-hidden while the stack is collapsed and Close itself lacks focus; actual F6 viewport focus expands the stack and exposes its name. The canonical default is the expanded low-priority state; collapsed fixtures retain that source distinction. Static 118px heights/offsets illustrate the measured default recipe at382px width; actual source measurement grows with wrapping. Source Toaster private content/text wrapper and type Icon are mapped explicitly; Button source styles apply to Action/Close, with meaningful names and no fabricated onOpenChange. Default low-priority Toast Root is genuinely nonmodal role dialog/aria-modal=false, with labelled/described title and polite viewport; higher urgency remains separately documented source behavior. Document theme/dir is caller context for source private portal; actions and timeout 0 persistent task feedback retain actual manager semantics. No page/node coordinate or arbitrary per-notification CSS identity is used.

Toast Root requires an actual ToastObject. Public Toaster wraps Provider/Portal/Viewport/List and defaults to the exported singleton toast manager; createToastManager/useToastManager are actual public exports. A mounted provider/Toaster is required to display manager events; the manager is an event emitter, not a promised pre-mount queue. Manager add(options)->id, update(id,object|updater), close(id?) and promise(promise,{loading,success,error}) retain their exact generic types. Duplicate id updates in place and refreshes timer. Provider defaults timeout5000ms, limit3; timeout0 disables auto-dismiss. Loading type has no timer; promise transitions that same toast to success/error, preserving promise resolve/reject for caller handling. Exceeding limit marks older objects limited/inert rather than immediately removing them. Closing and final removal are separate ToastObject onClose()/onRemove() callbacks, not fabricated Root onOpenChange. Root defaults nonmodal role=dialog (priority low), tabindex0, aria-modal=false and registered h2 Title/p Description relations. High priority uses alertdialog hidden from accessibility until focused, with a separate urgent alert mirror in Viewport; Viewport is labelled Notifications, region with polite/additions-text live behavior. No generic role=status is falsely attached to every toast. Timers pause during hover, focus and window blur, then resume remaining time. F6 enters notification viewport; Shift+Tab from viewport restores prior focus, and focus guards skip limited/ending entries. Escape closes only a toast containing actual focus. Absent type remains untyped; only explicit success/error/loading options select a type. Close is aria-hidden while collapsed and not itself focused; actual F6 viewport focus expands the stack and reveals Close. Close uses source native Button with default name Close toast; Action renders only with meaningful children, merges actionProps and does not automatically close. Swipe dismissal uses configured directions (default down/right), not a different confirmation event. This reference uses explicit persistent feedback for essential task outcomes, low priority by default, timeout0 for important actionable messages, named actions/Close and finite timed examples; disappearing notification text is never the only durable result.

Toasts do not trap focus or steal it when added. Actual F6/Tab focus routing reaches the viewport/toast/action/Close; Escape works when focus is inside that toast, not as a global close-all shortcut. Native Action/Close Enter/Space and disabled behavior are preserved. Action execution is independent from dismissal and onClose differs from onRemove after animation. High urgency, visible limits, pausing and source live-region branching remain explicit; this bounded reference is not a cross-AT announcement certificate. SOURCE_PRESENTATION_OBSERVED in SCXML records actual expanded/Close-focus presentation; it is an internal observation, not a new public event.
