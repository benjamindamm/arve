# Alert · semantische Komponentenreferenz

Present contextual information or a problem inside a page.

Status der neuen Domänenmigration: **complete** im begrenzten Referenzumfang. Stabile Teile, tatsächlich passende Source-Selektoren, semantische Tokenwerte und nutzbare Zustands-Fixtures wurden mit dem normalen Komponentenprüfpfad und der echten React-Verwendung geprüft. [Browsernachweis](../../validation/semantic-structured-browser-run.json); keine allgemeine Anwendungsfreigabe.

Alert retains its four actual source wrappers and optional caller SVG. Native 8/10px padding, 8px icon/action gap, 2px title/description gap, 10px corner and 16px icon become semantic metrics; native 464px width/78px height remain examples. The reference uses intrinsic grid rows, shared 14/20px text and an explicit caller class when an icon is supplied. Actions move below text at a chosen 28rem narrow-view boundary. Actual variant classes select default/destructive roles; color supplements text. The pinned root always renders role=alert: caller policy reserves dynamic insertion for urgent changes and avoids duplicate announcements or forced focus. Retry is a caller Button, not a fabricated Alert event.
