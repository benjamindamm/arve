Empty uses all six actual wrappers. Runtime EmptyDescription is a div even though its TypeScript props inherit p; the HTML projection follows runtime output. Native24px padding,16px section gap,14px corners,8px header gap,32px icon surface/16px glyph and10px icon corners are retained.384px text stack is an upper bound rather than fixed specimen width. A deeper native read finds18/28px title text inside a20px frame: the reference preserves text metrics and intrinsic height, avoiding native frame clipping. Title is a caller-supplied heading. Dashed outline is this chosen empty-collection composition, not a new public variant. Loading/error decisions and recovery actions belong to the caller; no automatic fetch/upload lifecycle is invented.
