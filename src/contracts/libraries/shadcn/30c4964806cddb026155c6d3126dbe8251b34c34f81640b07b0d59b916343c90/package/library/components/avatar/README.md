# Avatar · semantische Komponentenreferenz

Represent a person or entity with an image or fallback.

Status der neuen Domänenmigration: **complete** im begrenzten Referenzumfang. Stabile Teile, tatsächlich passende Source-Selektoren, semantische Tokenwerte und nutzbare Zustands-Fixtures wurden mit dem normalen Komponentenprüfpfad und der echten React-Verwendung geprüft. [Browsernachweis](../../validation/semantic-feedback-browser-run.json); keine allgemeine Anwendungsfreigabe.

Actual Root sizes sm/default/lg map to native 24/32/40px circles; source badge sizes map to8/10/12px. The primitive owns image loading/error and fallback delay. Root remains overflow-visible for the badge; image/fallback inherit circle clipping. Group retains native 8px logical overlap and pinned 2px rings. Native size/type artwork does not create a public type prop. Count has a selected default 32px presentation because its actual API has no size prop; applications may explicitly adapt className for other group recipes. Badge uses the pinned physical right/bottom anchor even in RTL; ordinary adjacent text conveys any essential status. Independently authored portrait assets are fixtures, not extracted native image claims.
