# Combobox · semantische Komponentenreferenz

Search options through an editable labelled input while keeping the query, highlighted item and selected value distinct.

Status der neuen Domänenmigration: **complete** im begrenzten Referenzumfang. Stabile Teile, tatsächlich passende Source-Selektoren, semantische Tokenwerte und nutzbare Zustands-Fixtures wurden mit dem normalen Komponentenprüfpfad und der echten React-Verwendung geprüft. [Browsernachweis](../../validation/semantic-pickers-browser-run.json); keine allgemeine Anwendungsfreigabe.

ComboboxInput wraps InputGroup; its actual native input slot is input-group-control, not an invented combobox-input. Source defaults showTrigger=true/showClear=false, but this reference deliberately composes named exported Trigger and named BaseUI Clear/ChipRemove with tabIndex 0 and showTrigger/showClear/showRemove disabled, because private icon-only wrappers offer no instance label prop. These helpers are transparent caller compositions, not new shadcn exports. Native input/chips frames are 32px with 10px corners; source popup 10px corner/4px inset, standard 28px minimum rows. Chosen 24px chips/6px corners/4px gaps wrap and remain usable at320px. Shared popup surface/InputGroup styles are explicit transitive dependencies; actual SourceList/option/chip/clear styles remain family-specific. Query highlight and selection/open callbacks stay distinct; source native editing, closed-Escape clear, source no-results and filtering rules are preserved. Open dismissal may reset query to the current selected label; only closed Escape performs the separate selected-value clear transaction. Static fixtures keep primitive roles/active-descendant IDs, with Root/Value/Collection/hook context ownership separate from DOM anatomy. Explicit aria-labelledby points to the real native label because source open-state outside hiding can otherwise remove the implicit HTML-label accessible name; a meaningful error text is linked to the input; The reference passes disabled to both Root and ComboboxInput because the wrapper default disabled=false is passed to its rendered InputGroupInput and can otherwise leave the native input enabled despite the Root lock; readOnly and selected arrays retain source behavior. Portal dir/theme and optional chips anchor belong the real Content/Positioner composition, never native specimen coordinates.

Combobox is a direct alias of ComboboxPrimitive.Root. Its generic selected value/defaultValue and onValueChange are distinct from inputValue/defaultInputValue/onInputValueChange, highlight and open callbacks. multiple changes values to arrays. Root items supplies filtering/Collection/Empty; default filtering is source locale-aware matching, autoHighlight=false, modal=false, and query changes alone do not commit a value. filteredItems/filter=null support explicit caller filtering; object values use itemToStringLabel/itemToStringValue and Object.is comparison unless overridden. Root autoComplete is a browser autofill hint (mapped to formAutoComplete), not the internal list/inline autocompletion mode. Input wraps the actual primitive input in InputGroup, defaults showTrigger=true/showClear=false and disabled=false; Content defaults bottom/start, offsets6/0 with optional anchor. List is listbox, Item is option, and virtual focus remains on input via aria-activedescendant. Empty requires Root items and keeps a polite status element mounted while changing its children. Group/Collection/Separator and useComboboxAnchor are concrete public parts. In multiple mode an accepted item press stays open when not filtering; filtering with input outside the popup closes it, while input-inside-popup clears the query with input-clear/isItemPress details. Multiple mode uses Chips/Chip/ChipsInput and source chip keyboard/removal behavior; showRemove defaults true. The private icon-only Clear/automatic trigger and automatic chip-remove wrappers expose no instance-specific label props. The chosen reference sets showTrigger=false/showClear=false and showRemove=false, composing explicitly named exported Trigger and named Base UI Clear/ChipRemove where needed. These are transparent caller compositions, not fictitious new shadcn exports. The reference opts auxiliary actions into native Tab order with explicit tabIndex=0; their source defaults are -1. Disabled/readOnly block value edits but readOnly still allows popup browsing. A canceled Combobox item-selection transaction returns before its dependent close, unlike Select which separately requests closing. Clearing selected/query state and popup dismissal use distinct cancellable source callback transactions; host-controlled props remain authoritative.

Input retains native editing, IME and selection. Arrow navigation highlights options virtually without moving DOM focus out of the input; disabled items cannot commit. Enter selects the highlighted item. Escape while the popup is open dismisses without committing highlighted arbitrary text. Crucially, Escape when the popup is already unmounted requests clearing both query and selected value (null in single mode or [] in multiple), unless disabled/readOnly; the same source details object carries that closed-Escape transaction. Any query reset and selected clear retain their own actual callback/prop authority. Named Clear/ChipRemove use actual primitive removal and return focus as prescribed by source. Multiple chips support source arrow/backspace/delete navigation, not six fake textboxes. No required asynchronous loading, validation or network success is inferred from static artwork.
