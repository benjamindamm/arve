# Table · semantische Komponentenreferenz

Present data in aligned rows and columns.

Status der neuen Domänenmigration: **complete** im begrenzten Referenzumfang. Stabile Teile, tatsächlich passende Source-Selektoren, semantische Tokenwerte und nutzbare Zustands-Fixtures wurden mit dem normalen Komponentenprüfpfad und der echten React-Verwendung geprüft. [Browsernachweis](../../validation/semantic-structured-browser-run.json); keine allgemeine Anwendungsfreigabe.

Table has nine semantic parts, including both actual DOM elements emitted by Table itself. Header cells retain 40px minimum extent; body cells retain 37px minimum extent and 8px insets, with 14/20px native typography mapped to shared roles. Native sample cell widths are content examples, not fixed columns. Text may wrap rather than being clipped to native single-line specimens; the actual wrapper provides overflow when content still needs it. Caption is deliberately placed below data with an explicit 8px separation. Native th/td/thead/tbody/tfoot and caller scope/caption carry semantics; no ARIA grid or sorting API is invented. Optional data-state=selected is an explicit caller presentation convention, not Table-owned selection behavior. Source TableRow emits no stored selection state.
