# Skeleton · semantische Komponentenreferenz

Reserve layout space while content loads.

Status der neuen Domänenmigration: **complete** im begrenzten Referenzumfang. Stabile Teile, tatsächlich passende Source-Selektoren, semantische Tokenwerte und nutzbare Zustands-Fixtures wurden mit dem normalen Komponentenprüfpfad und der echten React-Verwendung geprüft. [Browsernachweis](../../validation/semantic-content-browser-run.json); keine allgemeine Anwendungsfreigabe.

Skeleton is a decorative div whose source accepts caller className; text/avatar/card here are explicit caller classes, not invented shape props. Native16px text height,40px avatar,125px card height and8px/round corners are retained. Text/card width fills caller space rather than fixing the290px specimen width. The host supplies aria-busy and readable loading status; decorative shape is hidden from accessibility. Static Figma has no timing; a chosen2s pulse to50% opacity expresses source animate-pulse, and reduced-motion removes the animation without removing status.
