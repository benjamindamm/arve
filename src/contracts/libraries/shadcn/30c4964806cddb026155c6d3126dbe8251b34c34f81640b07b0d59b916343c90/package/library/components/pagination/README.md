# Pagination · semantische Komponentenreferenz

Navigate an explicitly supplied set of result-page destinations while identifying the current page.

Status der neuen Domänenmigration: **complete** im begrenzten Referenzumfang. Stabile Teile, tatsächlich passende Source-Selektoren, semantische Tokenwerte und nutzbare Zustands-Fixtures wurden mit dem normalen Komponentenprüfpfad und der echten React-Verwendung geprüft. [Browsernachweis](../../validation/semantic-native-browser-run.json); keine allgemeine Anwendungsfreigabe.

Pagination binds all seven actual exports and explicitly imports its real Button styling dependency. Native 32px square page actions and 2px gap are retained; destination wording does not become fixed previous/next widths. The selected pinned Button primitive renders these anchors with role=button and tabindex=0 because nativeButton=false, and intentionally supplies Space activation while Enter uses native href activation. The reference faithfully describes page actions backed by href, rather than incorrectly claiming plain link roles or Enter-only behavior. isActive supplies aria-current=page, data-active and the source outline variant; it does not change a stored page index. Previous/Next text and accessible names are caller-localizable; the reference follows the source hide/show text recipe at explicit 40rem. Unavailable boundary actions are omitted, not fake-disabled anchors. Ellipsis remains hidden and does not imply a menu. All page computation, routing/fetching and isActive updates remain caller-owned.

Root nav role=navigation is named pagination; Content/Item are ul/li. PaginationLink renders Button as anchor with nativeButton=false; isActive sets aria-current=page and outline instead of ghost, size defaults icon. Previous/Next default text and accessible English labels can be overridden for localization. Ellipsis is aria-hidden. The wrapper does not calculate page count, clamp indices, fetch results or implement a disabled prop on PaginationLink. Selected Base UI1.9 Button nativeButton=false supplies role=button and tabindex=0 on the source href anchor. Space activates on keyup; Enter uses native link activation. Modified pointer clicks still carry native href/modifiers. There is no roving arrow selection or automatic page state.
