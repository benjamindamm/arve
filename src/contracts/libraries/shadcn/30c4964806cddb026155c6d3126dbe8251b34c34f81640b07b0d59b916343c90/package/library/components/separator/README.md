# Separator · semantische Komponentenreferenz

Separate related regions or items visually.

Status der neuen Domänenmigration: **complete** im begrenzten Referenzumfang. Stabile Teile, tatsächlich passende Source-Selektoren, semantische Tokenwerte und nutzbare Zustands-Fixtures wurden mit dem normalen Komponentenprüfpfad und der echten React-Verwendung geprüft. [Browsernachweis](../../validation/semantic-content-browser-run.json); keine allgemeine Anwendungsfreigabe.

Actual selected BaseUI1.9 state is data-orientation=horizontal/vertical. The pinned wrapper utility text targets data-horizontal/data-vertical, which this runtime does not emit; the semantic adapter deliberately binds the observed actual orientation attribute without modifying upstream bytes. The native0px path dimensions describe a stroked line, not an invisible runtime element: the pinned wrapper explicitly supplies1px thickness, mapped to the semantic border width. Horizontal stretches across available width; vertical stretches to its flex/grid host block extent. Native100/120px specimen lengths remain host examples. No drag/resize or keyboard focus semantics are invented.
