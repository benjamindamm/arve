# NativeSelect · semantische Komponentenreferenz

Choose native single or multiple form options using the platform select interface.

Status der neuen Domänenmigration: **complete** im begrenzten Referenzumfang. Stabile Teile, tatsächlich passende Source-Selektoren, semantische Tokenwerte und nutzbare Zustands-Fixtures wurden mit dem normalen Komponentenprüfpfad und der echten React-Verwendung geprüft. [Browsernachweis](../../validation/semantic-native-browser-run.json); keine allgemeine Anwendungsfreigabe.

NativeSelect maps all five actual parts across three exports. ClassName belongs to the wrapper; source size=sm/default is a visual API and never a native numeric select size attribute. Native 36px height, 8px outer block inset, 10px inline inset, 8px gap and 8px corner are retained. CSS padding subtracts its included 1px border so the outer-edge-to-text inset stays faithful without inflating height to38px. The reference explicitly selects 32px for the source-supported compact size, with no invented native sm observation. Width is content-dependent and capped by the host. Source dir is forwarded only to the select, so the wrapper derives explicit direction from that actual child attribute; logical chevron position stays aligned even under the opposite surrounding direction. Multiple remains a true native multiple select with intrinsic platform height and no misleading single-select chevron. Option/optgroup Canvas/CanvasText follows the source system-color utility; multiple selected options explicitly retain system Highlight/HighlightText so that utility cannot erase the visible selection. Native labels, selected values, disabled options, popup/typeahead/modifiers and events remain platform-owned; no fake ARIA listbox or selection events are introduced.

Native Muster, Hashes und Messwerte bleiben vollständig separat in [Quellmustern](figma/source-specimens.json) und [Traceability](figma/traceability.json).

Die veröffentlichten Props/Callbacks und der [führende SCXML-Aktor](behavior.scxml) bleiben die Quelle des tatsächlichen Verhaltens. [HTML/ARIA](accessibility.html) und [Projektionsregeln](accessibility.rules.json) benennen die konkrete Verwendung, einschließlich notwendiger Caller-Beschriftung. Selectorbindungen sind ein expliziter React-/DOM-Adaptervertrag, keine erfundenen automatischen Shadow-DOM-Exports.

NativeSelectProps omits the native numeric size prop and replaces it with sm|default (default). Other native select props, including multiple, value/defaultValue, disabled, name and onChange are passed through. NativeSelectOption/OptGroup are option/optgroup. The extra ChevronDown is aria-hidden. className styles the surrounding wrapper, not the select.

The operating system/browser owns popup, arrow, typeahead, modifier selection and Escape behavior. This contract consumes the actual native change transaction; it does not equate every arrow key with a committed change. Escape may close a native picker, and does not fabricate an extra change/revert event. Disabled controls/options cannot be user-chosen; controlled value remains prop-authoritative.
