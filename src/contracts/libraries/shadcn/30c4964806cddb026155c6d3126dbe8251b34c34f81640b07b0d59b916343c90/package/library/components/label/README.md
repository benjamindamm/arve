Label is the actual native label wrapper, not an inferred FieldLabel primitive or automatic ARIA association. The source Label page itself depicts a FieldLabel instance from the same kit; its20px row and8px gap support the shared14/20px medium text and8px arrangement role. Optional field spacing and disabled opacity are explicitly caller context; no disabled prop is invented for Label. The host must bind htmlFor to a real labelable control and disable that control separately. Source instance widths are not runtime label widths. Logical layout supports RTL.
