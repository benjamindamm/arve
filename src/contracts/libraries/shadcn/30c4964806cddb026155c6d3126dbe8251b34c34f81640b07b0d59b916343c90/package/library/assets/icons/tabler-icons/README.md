# Tabler Icons · native Asset-Zuordnung

Quelle `provenance://source/.figma-pool%2Fshadcn.fig`, SHA-256 `ccbe95f20f501389a322d0f6de2c90ca79126a33355f1b31e2b1dcc7c8e2b3d5`, Seite `642:97`. [Vollständige Quellkarte](source-map.json) enthält 4963 native Einzelmaster mit IDs und Namen. Die Icons sind Assets und werden nicht als 4963 eigenständige UI-Controls registriert.

Die Originalgeometrie bleibt im gebundenen lokalen FIG-Export. Komponentenausschnitte enthalten benötigte Icons als native Abhängigkeiten. Separate SVG-Exporte, externe Iconversion, Lizenzzuordnung und eine programmgesteuerte Namensauflösung wurden hier nicht geprüft.

Ein Iconname beweist weder die Bedeutung eines Controls noch seinen zugänglichen Namen. Informative Icons brauchen im jeweiligen Kontext eine textliche Entsprechung; rein dekorative Ausblendung muss dort ausdrücklich entschieden werden. Keine allgemeine ARIA-Regel wird aus der Assetbibliothek übernommen.
