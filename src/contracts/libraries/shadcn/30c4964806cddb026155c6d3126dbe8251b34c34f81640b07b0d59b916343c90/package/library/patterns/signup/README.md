## Anordnung und Bedienung

Keep account data, consent and provider actions distinguishable. Preserve form order when an illustration is removed at narrow width; associate error feedback and explain any required data. Actual registration and consent policy remain open.

Die Regeln in diesem Abschnitt sind Autorenableitungen für den späteren Einsatz, keine im Bild ausgeführten Interaktionen. Tastatur, Fokus, Breakpoints, dynamische Inhalte und Backendabläufe bleiben ungeprüft.
