# Sidebar · Pattern-Draft

Navigation and workspace arrangements with grouped, nested, floating, collapsed and calendar examples. Avoid hiding the only route to a destination in a collapsed or hover-only surface.

## Anordnung und Bedienung

Keep navigation grouping and selected location explicit. Collapsed icon navigation still needs accessible names; overlays need their own focus lifecycle. Preserve a coherent order when secondary navigation changes.

Die Regeln in diesem Abschnitt sind Autorenableitungen für den späteren Einsatz, keine im Bild ausgeführten Interaktionen. Tastatur, Fokus, Breakpoints, dynamische Inhalte und Backendabläufe bleiben ungeprüft.
