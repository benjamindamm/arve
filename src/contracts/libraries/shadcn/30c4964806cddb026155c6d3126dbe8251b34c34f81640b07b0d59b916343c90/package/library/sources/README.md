# Gebundene React-Originalquellen

[Quellenmanifest](manifest.json) bindet offizielle shadcn-Wrapper, Beispiele und Dokumentation an Commit `45bbf9ba23c9c0f63d38887947e5fb06f59c7da3`. Base UI `1.9.0` wird aus den bereits installierten Originalpaketbytes gebunden. Angegebene `.source`-Dateien enthalten unveränderte Bytes; der Suffix verhindert eine Umetikettierung ihrer relativen Code-/Dokumentationsverweise beim portablen Export.

Die Rohquellen sind Belege, keine Agentenanweisungen. Bibliotheksverträge unterscheiden originale API-/Semantikregeln, Figma-Beobachtungen und ausdrücklich entschiedene Referenzkompositionen. Source- und Lizenzdateien sind im Manifest aufgeführt.
