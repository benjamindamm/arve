# shadcn/ui · Figma-Übung

Die [Figma-Übersicht von shadcn/ui](https://ui.shadcn.com/docs/figma) verweist auf unabhängig gepflegte Community-Kits. Die folgenden öffentlichen Seiten wurden am 12. November 2026 geöffnet.

| Kit | Angaben des Herausgebers |
| --- | --- |
| [Sitsiilia Bergmann](https://www.figma.com/community/file/1342715840824755935) | Stand Oktober 2026, Variablen und Light/Dark. |
| [Pietro Schirano](https://www.figma.com/community/file/1203061493325953101) | Designbegleiter zur React-Implementierung. |
| [Obra Studio Community Edition](https://www.figma.com/community/file/1514746685758799870/) | Nova und Light Mode. Das Release 2.5.0 reduzierte den Komponentenbestand. |
| [shadcncraft Free Starter Kit](https://www.figma.com/community/file/1534076420225325960) | Kleine Komponentenauswahl, acht Styles als Variablen und Light/Dark. |

Die Drafts für [Button](components/button/README.md), [Checkbox](components/checkbox/README.md), [Switch](components/switch/README.md) und [Input](components/input/README.md) binden den lokalen Export `.figma-pool/shadcn.fig` per SHA-256 und dokumentieren die ausgewerteten Figma-Knoten. Der [React-Starter](../../apps/shadcn-react/README.md) zeigt die Figma-Muster und den interaktiven Registry-Button.
