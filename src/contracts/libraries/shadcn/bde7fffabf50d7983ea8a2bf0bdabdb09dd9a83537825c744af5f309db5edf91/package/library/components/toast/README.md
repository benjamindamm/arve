# Toast · gebundene Navigations-/Ebenenreferenz

Present nonmodal actionable notifications with actual manager, announcement, timer, focus and close/remove lifecycle.

Offizieller shadcn-Commit `45bbf9ba23c9c0f63d38887947e5fb06f59c7da3` und Base UI 1.9.0. [Unveränderte Quellen samt Laufzeit-ESM, Typen und Hashes](../../sources/manifest.json); [öffentliche Wrapper-/Aliasinventur](../../sources/react-api-inventory.json).

Toast Root requires an actual ToastObject. Public Toaster wraps Provider/Portal/Viewport/List and defaults to the exported singleton toast manager; createToastManager/useToastManager are actual public exports. A mounted provider/Toaster is required to display manager events; the manager is an event emitter, not a promised pre-mount queue. Manager add(options)->id, update(id,object|updater), close(id?) and promise(promise,{loading,success,error}) retain their exact generic types. Duplicate id updates in place and refreshes timer. Provider defaults timeout5000ms, limit3; timeout0 disables auto-dismiss. Loading type has no timer; promise transitions that same toast to success/error, preserving promise resolve/reject for caller handling. Exceeding limit marks older objects limited/inert rather than immediately removing them. Closing and final removal are separate ToastObject onClose()/onRemove() callbacks, not fabricated Root onOpenChange. Root defaults nonmodal role=dialog (priority low), tabindex0, aria-modal=false and registered h2 Title/p Description relations. High priority uses alertdialog hidden from accessibility until focused, with a separate urgent alert mirror in Viewport; Viewport is labelled Notifications, region with polite/additions-text live behavior. No generic role=status is falsely attached to every toast. Timers pause during hover, focus and window blur, then resume remaining time. F6 enters notification viewport; Shift+Tab from viewport restores prior focus, and focus guards skip limited/ending entries. Escape closes only a toast containing actual focus. Close uses source native Button with default name Close toast; Action renders only with meaningful children, merges actionProps and does not automatically close. Swipe dismissal uses configured directions (default down/right), not a different confirmation event. This reference uses explicit persistent feedback for essential task outcomes, low priority by default, timeout0 for important actionable messages, named actions/Close and finite timed examples; disappearing notification text is never the only durable result.

Toasts do not trap focus or steal it when added. Actual F6/Tab focus routing reaches the viewport/toast/action/Close; Escape works when focus is inside that toast, not as a global close-all shortcut. Native Action/Close Enter/Space and disabled behavior are preserved. Action execution is independent from dismissal and onClose differs from onRemove after animation. High urgency, visible limits, pausing and source live-region branching remain explicit; this bounded reference is not a cross-AT announcement certificate.

Concrete names, hrefs/current page, durable toast result, callback handling, desktop icon collapse and explicit mobile Close are caller composition. Native source code, exact defaults/limitations and independent primitive actors remain authoritative; no generic global selected state or extra public event is invented.

Die semantische HTML-/CSS-Projektion implementiert keine zweite Primitive-Laufzeit. Das normale Prüfziel verwendet gebundene Originalwrapper. Source-Callbacks, native Gesten, einzelne Actorzustände und kontrollierte Props werden im SCXML getrennt beobachtet; der Abschluss ist eine ausreichende Referenzbeschreibung, keine allgemeine Laufzeit-/AT-Zertifizierung.
