# Table · React-Inhaltsreferenz

Present data in aligned rows and columns.

## Belegte Oberfläche

Offizieller shadcn-Commit `45bbf9ba23c9c0f63d38887947e5fb06f59c7da3`. [Originalquellen und Hashes](../../sources/manifest.json); [exakte exportierte Typen, Defaults und Quellzeilen](../../sources/react-api-inventory.json). Diese Familie exportiert `Table`, `TableHeader`, `TableBody`, `TableFooter`, `TableRow`, `TableHead`, `TableCell`, `TableCaption`. `interface.json` bewahrt die genaue Propoberfläche jedes Wrappers; sie ist keine frei erfundene native Widget-API.

Table wraps a native table in an overflow container; header/body/footer/head/row/cell/caption retain their native tags. No sorting, filtering, row selection or grid keyboard protocol is built in. Data Table composes those features separately. Parent updates replace rows without moving focus automatically.

## Semantik und Referenzentscheidungen

Native caption, header scopes and textual cell values communicate the full table without color or hover. Complex header relationships use IDs/headers as required by that dataset.

The sample dataset, caption and explicit scopes are caller-supplied reference content. No ARIA grid role or roving tabindex is added to an ordinary table.

This default content wrapper does not install a keyboard listener or roving focus. Native links/buttons/inputs in the chosen children retain their own documented semantics. Label delegates native focus through its associated control.

`accessibility.html` ist die konkrete, typzulässige Referenzkomposition. Native Elemente werden für ihre tatsächliche Bedeutung verwendet; fehlende native Überschriften/Labelbezüge werden als bewusste Caller-Komposition geliefert, nicht als automatisch vorhandene Wrapperfunktion ausgegeben.

## Verhalten und Komposition

SCXML bildet ausschliesslich den tatsächlich passiven React-Lebenszyklus ab: Props ändern die Darstellung ohne erfundene Wertevents; Unmount entfernt die Darstellung. Aktivierung und Escape erzeugen keine eigene Aktion oder Auswahl. Das ist kein Dummy-Control-Lebenszyklus: diese Wrapper speichern tatsächlich keinen solchen Controlwert. Interaktive Nachfahren behalten ihre eigene führende Komponente.

Zugeordnete Nachfahren: keine vorgeschriebene interaktive Kindkomponente.
